# Original experiment code

Run these scripts from this directory after installing the parent repository with experiment dependencies. Filenames, imports, protocols and relative paths are retained from the research workspace. The `topobridge_*` and `*_oracle.py` files also supply shared utilities to the final model; their early diagnostic results are not the MaskTopo paper's primary results.

Use [the reproduction guide](../docs/reproduction.md) for the correct entry points and protocol distinctions. Use `python SCRIPT.py --help` to inspect stage and path arguments. Do not run all scripts as a single undifferentiated experiment.

The original filenames containing `test_once`, freeze manifests and data gates preserve historical provenance checks. Original manifest paths can refer to the source machine. They require compatible generated artifacts and are not interchangeable with new-training manifests. The provided `实验记录` metadata contains archive indexes, split information and checksums rather than images or credentials.
